# 入力記録

自分が確定した文を、Mac の中のファイルに残す仕組みです。あとで変換（Zenzai）や音声認識を自分好みに育てるための材料にします。

## 目的

- キーボード入力：Zenzai を自分の文で追加学習するための「読み → 表記」の組を集める
- 音声入力：自分の言葉の言語モデルや、認識結果の直しを作るための文を集める

この段階では集めるだけです。学習や認識への反映は、まだ行いません。

## 記録するもの

記録はまとめて「入力記録」（`InputJournal`）と呼び、次の 2 種類に分けます。

### 変換の記録（`InputJournal.ConversionEntry`）

キーボードで打った読みと、確定した表記の組です。

| 項目 | 中身 |
| --- | --- |
| `at` | 確定した時刻（ISO 8601） |
| `reading` | 読み（カタカナ）。Zenzai が受け取る読みと同じ形 |
| `text` | 確定した表記 |
| `leftContext` | 確定した位置より前の文（同じ行の、最大 30 文字） |
| `commit` | 確定のしかた。`whole`＝未確定文字列をまとめて確定、`candidate`＝候補を選んで先頭から一部を確定 |

- `whole` の読みは、未確定文字列の読み全体です。
- `candidate` の読みは、選んだ候補の読み（辞書の読み）です。

### 音声の記録（`InputJournal.VoiceEntry`）

音声入力で確定した文です。

| 項目 | 中身 |
| --- | --- |
| `at` | 確定した時刻（ISO 8601） |
| `text` | 確定した文（認識結果をつないだもの） |
| `engine` | 使った認識の仕組み。`speechTranscriber`＝高精度、`standard`＝互換 |
| `leftContext` | 確定した位置より前の文（同じ行の、最大 30 文字） |

認識結果を自分で直したときの「直しの組」は、まだ記録しません。

## 残す場所と形

- 場所：azooKey のアプリケーションサポートのフォルダの下の `InputJournal/`
  - `conversion.jsonl`：変換の記録
  - `voice.jsonl`：音声の記録
- 形：JSON Lines（1 行に 1 件）
- 1 つのファイルが 20MB を超えたら、古いほうを `〜.old.jsonl` として 1 つだけ残し、新しいファイルに書き始めます（古い `.old` は消えます）
- ファイルは自分だけが読み書きできる権限（600）で作ります

## 決まり

- 設定（カスタマイズ → 入力記録 →「入力記録を残す」）がオンのときだけ残します。既定はオフです
- どこにも送りません
- パスワードの入力中（OS が安全な入力にしているあいだ）は残しません
- 空の確定は残しません
- 設定画面の「フォルダを開く」で記録の場所を開け、「消す」ですべて消せます
- 書き込みは専用のキューで行い、キー入力を待たせません

# 新しい日本語入力 コンセプト：ペルソナとフィードバックの回し方

モックアップ（キャンバス）：https://claude.ai/artifact/L8FWh8ERqKqKsJFFjRQD4J

- 0 全体の考え方
- A 文節ラティス：全部の文節の候補を同時に縦に積む。⌥＋文字ラベルで1打で選ぶ
- B 意味で選ぶ：同音異義語を絵と意味のカードで出す。自動で変えたときは理由を出し、⌘Z で戻せる
- C 流して、文末で直す：打つ間は点線だけ。「。」で迷った所だけまとめて出す

## フィードバックの回し方

1. モックアップを更新する
2. 下の 5 人のペルソナそれぞれに、サブエージェントとして同じ資料を見せ、決まった形式で感想をもらう
3. 結果を `rounds/round-NN.md` にまとめる（ペルソナごとの要点、共通する声、ぶつかる声、次に直すこと）
4. 直すことを決めてモックアップに反映し、次の回へ

ペルソナは回をまたいで固定する。変えるときはこのファイルを直し、回の記録にその旨を書く。

第2回からは、最新の案だけを見せる。サブエージェントは毎回新しく立て、前の回の感想は見せない（前回への気づかいで点が甘くなるのを避けるため）。

## 収束の判定

次の 3 つをすべて満たした回で「収束」とする。

1. **点数**：5 人全員が、最新の案に 4 以上を付けた
2. **拒否**：「これだけは嫌だ」に挙げたことが最新の案に当てはまる、と答えた人が 0 人
3. **新しい論点**：設計を変える必要がある指摘のうち、前の回までの記録にないものが、全体で 2 件以下

次のどれかに当たったら、収束していなくても止めて報告する。

- 5 回まわした
- 2 回続けて、合計点が上がらなかった
- エンジンの変更が必要な指摘や、ペルソナどうしでどうしても両立しない指摘が残り、モックアップでは決められない

## ペルソナ

### P1 佐藤 由美（46歳・総務の事務職）

- 1日中、メールと社内文書を書く。ローマ字入力で速い（毎分 100 字ほど）
- macOS 標準の日本語入力を 15 年使っていて、ライブ変換はオン
- 手元を見ずに打ち、変換ミスは確定後に気づいて直すことが多い
- 気にすること：速さ、慣れた操作が崩れないこと、余計な表示で集中が切れないこと

### P2 田中 健太（32歳・ソフトウェアエンジニア）

- コード、チャット、技術文書。日本語に英単語・数字・記号が混ざる
- キーボード操作を好み、Vim のキー操作に慣れている。マウスはほぼ使わない
- 「2026年」「v1.2」のような数字を変換中によく打つ
- 気にすること：キー操作の一貫性、数字・英字との衝突、反応の速さ

### P3 山本 澄子（58歳・小説家・エッセイスト）

- 長い文章を書く。かな入力。言葉の選び方と表記の揺れに厳しい
- 同音異義語や「ひらく／閉じる」（ひらがなにするか漢字にするか）を1語ずつ確かめたい
- 文章を考えながらゆっくり打つ。自動で表記が変わるのを嫌う
- 気にすること：表記を自分で決められること、勝手に変わらないこと、文の流れを読みながら直せること

### P4 鈴木 陽菜（20歳・大学生）

- 普段はスマホのフリック入力と予測変換。パソコンはレポートを書くときだけ
- 変換キーや文節の区切りの操作はほぼ知らない。違ったら全部消して打ち直す
- 気にすること：見ただけで分かること、覚えることが少ないこと、スマホと同じ感覚で選べること

### P5 高橋 正雄（74歳・退職した元教員）

- 地域の会報や家族へのメールを書く。人差し指で1文字ずつ、ゆっくり打つ
- 老眼で、画面を拡大して使っている。小さく薄い文字は読めない
- 画面に急に何かが出たり、勝手に変わったりすると、何が起きたか分からなくなる
- 気にすること：文字の大きさと濃さ、表示が落ち着いていること、間違えてもすぐ戻せること

## サブエージェントへの質問の形式

各ペルソナには、次の形で答えてもらう。

1. 第一印象（ひとこと）
2. 案ごと（A・B・C）に
   - 使ってみたいか（1〜5）
   - 良いと思った点
   - 困りそうな点（自分の普段の場面を具体的に）
3. 一番使いたい案と、その理由
4. 「これだけは嫌だ」ということ
5. こう変えてほしいという提案（あれば）

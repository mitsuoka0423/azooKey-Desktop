変換パネルの状態と UI

見た目のデザインを話すための資料です。変換パネルのどの部品がどの状態でどう見えるか、状態が変わるときに何が動くかをまとめました。部品とアニメーションには名前をつけてあるので、「文節カードの注意バーを太くしたい」のように名前で指せます。

元にしたのは main のコード（PR #15 の候補のページ送りまで）です（LiveConversionPanelView.swift、LiveConversionCandidateListView.swift、LiveConversionPanelModel.swift）。見本の文字と候補は例です。

状態遷移図

状態は 4 つ（パネルなし、入力中、文節選択中、それぞれのたたむ／広げる）です。矢印の上はきっかけのキー、下の 名前 はそのときの見た目の変化（遷移）の名前です。アニメーションがあるのは 登場 だけで、ほかは一瞬で描き替えます。

S1 の一形態

打ち始めや短い語のとき。文節の仕切りはなく、本文の未確定文字列も分けません（太い下線もない）。

  • 候補の吹き出しは最小幅 140 なので、文節カードより広くなりやすい
  • 英字だけで打った文節では、候補に打ったとおりの英字（手がかり「英字」）が入る

パネルの位置

位置はどの状態にも重なる性質です。パネルの左端は、変換の始まりの位置より 12pt 左。本文の行とは 4pt 離します。

遷移とアニメーション

見た目が変わるきっかけ（遷移）に名前をつけました。今アニメーションがあるのは 登場 の 1 つだけで、その動きを ドロップイン drop-in と呼びます。

ドロップイン drop-in の見本

ボタンを押すと、ブラウザで同じ動き（0.12 秒）を再生します。「10 倍遅く」で動きの形を確かめられます。動きを減らす設定にしている場合は再生しません。

デザインで話すときの手がかり

今の作りから読み取れる、見た目の論点です。決めたものではありません。

  • 入力中と文節選択中は見た目が同じ。今どちらにいるかを見せるかどうか
  • 対象移動で候補の吹き出しが一瞬で飛ぶ。動きをつけるか
  • 描き替えのたびにパネルの幅と高さが変わる。打つたびに揺れて見えないか
  • 自信が低くて対象でもある文節は、読みのオレンジがアクセント色に勝つ。対象であることが伝わるか
  • 退場にアニメーションがない。登場と対にするか
